# Java Assignment 1

This repository contains solutions to five Java programming questions.

## Questions

1. **Basic Mathematical Operations** — methods for addition, subtraction, multiplication, division, remainder, square, cube, and absolute value.
2. **One-Dimensional Array Operations** — insertion, deletion, linear search, binary search, maximum value, even/odd counting, and insertion sort.
3. **Matrix Operations** — addition, subtraction, multiplication, transpose, and checks for square, diagonal, and identity matrices.
4. **String, StringBuffer, and StringBuilder** — examples of the required String methods and common mutable-string operations.
5. **Bank Management System** — console-based account creation, deposit, withdrawal, balance enquiry, account details, and exception handling.

## Requirements

- Java JDK installed
- Any Java IDE (such as Eclipse) or a terminal

## Run a program

Open a terminal in this folder and run one question at a time. For example:

```bash
javac Question1.java
java Question1
```

Replace `Question1` with `Question2`, `Question3`, `Question4`, or `Question5` to run another solution.

Each question is a separate program. `Question5.java` contains both the `BankAccount` class and the `Question5` main class.
